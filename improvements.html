10 / 10 Convex Backend apps/web/convex/entries.ts

Atomic Field Sanitation & Type Conversion Orphan Keys

Problem & Defect
In update mutation, converting an entry from "event" to "task" leaves previous start, end, and loc in the DB document because Convex db.patch does not remove unmentioned keys. Furthermore, clearing loc or detail fails because empty string falsiness skips patching, preventing users from ever erasing saved details.
Proposed Fix & Implementation Seam
Explicitly sanitize patch payloads. Set unset fields to undefined or delete orphaned properties during type transitions. Treat args.loc !== undefined as an explicit field replacement so passing empty string clears the field.
9 / 10 Date Domain packages/core/src/date.ts

Now-and-Next Midnight Boundary Logic Failure

Problem & Defect
In getNowAndNext, active events are checked with startMin <= nowMin && nowMin < endMin. If an event spans across midnight (e.g. 23:30 to 01:00), endMin (60) is smaller than startMin (1410), rendering the condition permanently false and hiding active events.
Proposed Fix & Implementation Seam
Detect overnight spans when endMin < startMin and switch check condition to (nowMin >= startMin || nowMin < endMin). Ensure current active event status reliably highlights late-night entries.

Problem & Defect
